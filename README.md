# Teddy's Burger, refonte du site

Refonte du site de Teddy's Burger, snack à Anse-Bertrand (Guadeloupe). Site statique HTML, CSS et JavaScript, sans dépendance.

- Aperçu : https://yui971.github.io/teddys-burger/
- Carte et prix : `tools/menu.json`, puis `python3 tools/build.py` pour régénérer les pages
- Build pour l'aperçu GitHub Pages : `python3 tools/build.py --base /teddys-burger/ --preview`
- Tests du loader : `node tools/test-loader.mjs`
